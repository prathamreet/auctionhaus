## What lives here

Anything generated by the simulator after the paper was locked. Future post-paper runs that test the corrected `train.v2.ts` pipeline (with multi-auction corpora and real `sellerId` from the manifest) also belong here.

The corrected trainer `train.v2.ts` reads from this directory plus any new runs in the parent `runs/` folder; it writes only to `fraud.classifier.candidate.ts` so the paper snapshot stays untouched.
