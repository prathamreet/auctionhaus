Comments to the Authors The manuscript presents the "Atomic Ladder Protocol," a serializable transaction protocol designed for concurrent proxy bidding in real-time online ascending auctions. The protocol preserves intermediate increment bid records within a single atomic database transaction while preventing deadlocks using a two-tier global lock ordering scheme. Major Strengths: Strong theoretical rigor with formal proofs for log fidelity, Vickrey equivalence, conflict serializability, and deadlock freedom. Excellent empirical benchmarks comparing direct row-locking with a Redis Stream event-sourced sequencer (sustaining 975 bids/s with 8.1 ms p95 latency at 100 VUs). Areas for Improvement: Discussing performance behavior in multi-node distributed database environments (beyond single-node PostgreSQL/Redis testbeds) would add valuable depth to the evaluation. 11.
