\noindent We submit our research manuscript titled \textbf{``Real-Time Shill-Bidding Detection via Online Bid-Graph Analytics in Live Auction Platforms''} for consideration for publication in your journal.

\vspace{0.5em}

\noindent This work addresses shill bidding and collusion in live auctions. While prior literature focuses on offline, post-hoc batch analytics operating after an auction closes, this paper introduces an in-process sliding-window directed outbid graph permitting sub-millisecond streaming feature extraction and logistic regression classification during active bidding. The platform extracts five streaming metrics -- including bid frequency, response latency, price increment ratio, seller co-occurrence, and outbid reciprocity -- to feed a lightweight machine learning engine. Additionally, the system incorporates cryptographic sealed-bid commitments via a SHA-256 commit-reveal protocol and resolves critical database lock contention. By integrating an asynchronous Redis Stream sequencer, transactional throughput scales substantially, preserving server performance during high-concurrency event loops.
